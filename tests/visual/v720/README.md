## 已实际复核

- 用户：320 / 390 / 430 / 768 / 1440宽；最窄较大字体双列无横向溢出，触控按钮不挤压。
- 管理：390 / 430 / 1440宽；留言人、卡片操作、筛选、复选框、对话气泡与审核弹窗。
- 发布：430×932滚动前后固定栏top846 / bottom920，按钮不随页面尾部上移。
- 助手：桌面手机框left472.5 / right952.5；十秒后浮标right952.5，收边留在框内。390×500短屏弹窗top12 / bottom488，输入完整可见。空白关闭与重新打开保留未发送草稿。
- 配色：检查浅色回归、OLED黑底与灰色层次、输入框、次级文字、消息回执、原色照片、腾讯SDK原生夜间底图。DOM文字对比诊断辅助查找问题，不视为含图片 / 渐变的全量无障碍认证。
- 版本：隔离环境中双端预览、未勾选拒绝发布、检查后发布成功、普通管理员不见草稿与用户接口不泄露管理端说明。线上部署只生成待检查草稿。

## 使用与限制

修改共用组件时按上述尺寸复查两种外观、空 / 有数据、长文字、弹窗和页面尾部，并更新对应截图与manifest。浏览器短屏是布局检查，真实手机系统相机、软键盘、返回手势与OLED物理观感仍需设备验收。小程序本版未编译、预览或发布。
