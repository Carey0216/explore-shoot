# Java 依赖与许可

版本由 pom.xml 和 Maven 解析固定；构建时依赖自身的 LICENSE / NOTICE 会随 JAR 保留，不另复制第三方源码。项目免费使用这些库不代表地图或云服务无使用条件。

| 依赖 | 用途 | 许可与官方来源 |
|---|---|---|
| Spring Boot 4.1.1 / Spring / Tomcat | HTTP 服务、依赖注入、JUnit 测试集成 | [Apache 2.0](https://github.com/spring-projects/spring-boot/blob/main/LICENSE.txt)；传递依赖以各自 Maven 工件声明为准 |
| Jackson Databind 2.20.1 | 历史 JSON 与接口序列化 | [Apache 2.0](https://github.com/FasterXML/jackson-databind/blob/2.20/LICENSE) |
| Bouncy Castle bcprov 1.83 | 与旧密码兼容的 scrypt | [Bouncy Castle 许可](https://github.com/bcgit/bc-java/blob/main/LICENSE.html) |
| ZXing core 3.5.4 | 本地二维码生成 / 测试解码 | [Apache 2.0](https://github.com/zxing/zxing/blob/master/LICENSE) |

Maven 3.9.16 来自 Maven Central，下载校验 SHA-512，工具文件只在本机缓存。前端 / 坐标库 / AI 模型原许可说明继续保留，导航语音模型安装工具保留下载来源及许可；运行数据、模型权重和本机密钥不提交。
