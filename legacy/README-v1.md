# 探索与拍摄 · 本地交互原型

依据《02 探索与拍摄 校级项目申报书.doc》的五个业务模块制作，用于查看项目成型后的操作流程。用户端和管理端共用本地服务，进度、照片和维护资料保存在本机。

## 启动

双击 **启动项目.cmd**。浏览器打开 http://127.0.0.1:4174 。当前电脑已安装 Node.js，无需 npm 安装、数据库安装或外部网络。服务只监听本机，不对局域网和互联网开放。

- 用户端：http://127.0.0.1:4174/#explore
- 管理端：http://127.0.0.1:4174/admin
- 管理员：`admin`
- 本地演示密码：`Explore2026!`
- 停止：双击 **停止项目.cmd**，已有数据会保留。

管理员会话有效期为 12 小时，重启服务后需要重新登录。可通过启动前设置环境变量 `ADMIN_PASSWORD` 更换管理密码；网页上的默认演示密码提示不会自动更新。

## 推荐体验顺序

1. 选择 15 / 20 / 30 分钟、单人 / 双人、强度和主题。选择 30 分钟与“多走一点”可以看到全部三条路线。
2. 打开路线，查看步行、停留、缓冲的计算结果；选择个性化模板、固定任务或普通导览，确认开始。
3. 标记任务完成，或填原因后跳过；可暂停、恢复、提前结束。可以上传 JPG、PNG、WebP 照片。
4. 完成所有任务（或跳过）后保存探索；在探索手记中编辑感受、评分、照片，下载包含照片的独立 HTML 文件，或删除记录。
5. 进入管理端，编辑点位的来源与开放条件、登记实走时间、编辑和审核模板。
6. 在体验过程中关闭一个未完成点位，返回用户端后会看到阻止继续的提示。系统没有虚构替代捷径，可提前结束再选择其他路线。
7. 管理端查看本机操作产生的体验反馈、CSV 导出、模板回退日志和资料版本记录。

## 已实现的范围

| 申报书模块 | 本版实现 |
|---|---|
| 点位与任务资料管理 | 8 个示范点位、3 条路线、16 个模板；来源、核实日期、允许动作、开放条件；编辑、审核、维护版本与计时历史 |
| 偏好与路线 | 15/20/30 分钟、1/2 人、强度、主题；固定路线顺序；步行 + 每站 2 分钟停留 + 预算 20% 缓冲 |
| 受约束任务 | 后端检查点位/路线状态、模板审核、时间预算；按人数匹配任务；模型未配置时明确回退模板并写日志 |
| 现场体验与反馈 | 手动完成、暂停恢复、跳过原因、提前结束、刷新续接、点位关闭检查、反馈与评分 |
| 照片与回忆 | 上传压缩、清理定位元数据、任务与照片对应、个人可见、独立 HTML 下载、删除记录与照片 |

三条示范路线最短估算分别为 15、19、28 分钟；默认 20 分钟轻松散步只匹配第一条。主题用于优先推荐，主题没有匹配路线时会给出其他可用路线，不伪造点位。

## 数据与隐私

- 主数据：`data/store.json`。使用临时文件写入后原子替换，以避免半写入状态；适合单机小规模演示。
- 用户身份使用当前浏览器的随机 HttpOnly Cookie。另一个浏览器不会自动看到之前的手记；清除 Cookie 后原身份不可自动找回。当前不是正式的注册登录系统。
- 照片会在浏览器缩小到最长边 1800 像素并重新编码为 JPEG，服务端再移除 APP1 / APP13 / 注释元数据。原文件限 10MB、提交 JPEG 限 5MB，每项任务一张照片。
- 管理端不返回照片内容和用户 Cookie 身份，只展示匿名体验、反馈与是否有照片。
- 删除探索记录会删除其照片和反馈；去标识的生成检查日志保留，用于检查任务来源。
- 照片不会发给模型，整个演示不调用云端服务。校园配图已保存在本地，是 AI 生成的虚构校园，非真实学校照片。
- 独立 HTML 下载文件留在用户选定的下载目录；应用内删除不会删除已下载副本。
- 备份时先停止服务，再复制 `data` 文件夹；恢复时先停止服务，再恢复此文件夹。当前没有自动备份/账号找回。

## 与正式申报方案的边界

这是用于看成型效果的本地功能原型，不代表完成一年期项目和实地研究。

- 目前使用原生 JavaScript 网页 + Node.js 本地后端 + JSON 文件存储，便于直接运行。正式方案的 Vue / Spring Boot / MySQL 架构尚未实施；后续可按相同业务接口迁移。
- AI 模型 API、真正的语义生成/审核、费用统计尚未接入，界面明确标识“本地模板模式”。不能据此声称 AI 效果优于固定任务。
- 8 个点位、路线距离、时长、开放条件均为虚构演示数据，待真实校园采集与至少三次实走。示意图不提供实时定位或导航。
- 不含公开社区、自动评分、人脸识别、AR、自动导航，遵守申报书首版范围。
- 已开始的体验保存任务快照与资料版本；点位关闭会重新检查未完成任务。没有已核实替代方案时允许结束；不会自行生成替代路径。
- 管理端的数量、评分、完成率均来自本机操作，不预填试验成绩；60 份双评审、12 个独立体验单元等研究工作尚未开展。

## 项目结构

```text
dist/index.html      页面入口
dist/app.js          用户端、管理端与交互逻辑
dist/style.css       响应式样式
dist/assets/         本地配图
seed.cjs             8 点位 / 3 路线 / 16 模板初始资料
server.cjs           本地 API、权限检查、持久化、照片清理、手记导出
data/store.json      首次启动自动创建的本机数据
start.ps1            后台启动和健康检查
stop.ps1             精确停止本项目的服务进程
tests/integration.cjs  隔离数据的功能检查
```

测试命令：`node tests/integration.cjs`。测试使用另一个端口及独立测试数据，不修改用户的演示资料。
